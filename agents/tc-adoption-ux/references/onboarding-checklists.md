# Onboarding & Adoption Checklists

## 🚀 First-Run (Instance Admin)
- [ ] **Site Identity**: Set `siteName`, `siteDescription`, and `logo`.
- [ ] **Public Connectivity**: Verify `publicUrl` is reachable (essential for AP/GunDB).
- [ ] **Admin Security**: Change default `tunecamp` password.
- [ ] **Storage Config**: Configure `musicDir` and verify permissions.
- [ ] **Federation Check**: 
    - [ ] Zen peers connected.
    - [ ] ActivityPub actors generated and keys valid.
    - [ ] Subsonic API enabled for mobile client testing.

## 🎨 Artist Onboarding
- [ ] **Profile Setup**: Bio, links, and profile picture.
- [ ] **First Release**: 
    - [ ] Upload audio (FLAC/MP3).
    - [ ] Set visibility (Public/Unlisted).
    - [ ] Enable AP Broadcast.
- [ ] **Wallet Connection**: For Web3 payments/donations.

## 🎧 Listener Adoption
- [ ] **Roaming Discovery**: Explain how to log in with an existing GunDB ID.
- [ ] **Network Exploration**: Guide through the "Network" page.
- [ ] **Client Setup**: Instructions for connecting apps like Amperfy or Symfonium via Subsonic.

## 📉 Success Metrics
- [ ] **Time to First Track**: Minimize time from install to first play.
- [ ] **Cross-Instance Engagement**: Track successful logins via roaming.
- [ ] **Follower Growth**: Measure ActivityPub interactions from Mastodon/Funkwhale.
